# Suno BGM便携工作流

这是源suno-bgm-workflow1.1.1的分享裁剪版，独立名称/版本；不覆盖原技能，不包含本机案例/任务ID/目录。下载单项优先读[suno-native-download](../suno-native-download/SKILL.md)，不为下载已有作品生成新音乐。

制作前读取同事项目的原始brief及已有记录，明确类别、时长、候选数量、模型/设置、工作区、积分授权与审核入口。没有当前授权不Create；不能继承别人的类别数量、测试工作区、会员或账户。提示词/中文含义/实际提交字段分别保留。

生成只用当前项目允许、实际已核对的浏览器与账号，单页一个控制者。确认Instrumental实际设置；页面无开关时如实记录空Lyrics与可见语义，不能伪造开关。Instrumental/Exclude不保证成品无意外人声。每次正常Create后核对真实新ID/队列、输入关联、页面实际时长和费用；未确认接收时保持原字段，查原结果，不盲重发。当前工具拒绝不换入口绕过；本人身份/2FA/系统解锁交本人，正常可见验证仅在用户明确授权且工具允许时处理，不使用自动solver或隐藏证明。

所有生成/账单结算稳定后，串行下载已有自有原曲。默认每首一种原生MP3；包内已验Studio合同只有WAV，不切普通授权补MP3。记录正常生成积分与每次下载额外消耗，文件不覆盖，复用有效原件。下载同client前后额度相同才描述本次免额外消耗。

ID/title/model/settings/prompt/result/native-format/path/bytes/SHA/duration/full-decode证据对应。同一批技术完整性统一核验后再交项目指定审核；解码、元信息、静音播放不判断情绪/人声/接缝。听感未评就写待试听，1/2是随机候选非排名。不擅自发布、送出音频或抄参考旋律；网页资料用同事既有模板，真实新音频才能新增播放器，保留历史与反馈。
